🔧 Resend Kurulum Rehberi (1 dakika)

  1. resend.com git → Sign up (Google ile)
  2. Dashboard → API Keys → Create API Key → Key'i kopyala (re_xxxx...)
  3. Render.com → senin pazaryerios servisine gir → Environment → Add Variable
  4. Key: RESEND_API_KEY Value: re_xxx kopyaladığın key → Save
  5. Bir tane daha ekle: Key: FROM_EMAIL Value: PazaryeriOS <onboarding@resend.dev>
  6. Render otomatik yeniden deploy edecek → Log'da RESEND:AKTIF yazacak
  7. Buradan test maili gönder → Gerçek mail gelecek!

Ücretsiz: 3.000 mail/ay, 100 mail/gün. Kendi domainini bağlarsan sınır kalkar.
